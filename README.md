A Node program that writes one original line of plain text — an alien tourist's review of planet Earth after a two-day visit — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is 193 characters, carries a five-star verdict, and ends on the alien's deadpan conclusion about a species that rehearses terror for fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
